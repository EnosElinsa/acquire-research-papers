# Sources and venue coverage

Run `arp sources` for the offline inventory or `arp sources --spec <corpus.yaml>` for every requested venue/year slice. This needs no configured credentials or publisher browser. It reuses the live providers' venue/type gates and the Crossref identifier gate. An available capability is not a successful live fetch. Inspect `coverage.jsonl` and `discovery-errors.jsonl` after discovery.

| Source and primary documentation | Role and supported scope | Limit / acceptance evidence |
| --- | --- | --- |
| [ACL Anthology](https://aclanthology.org/) | Official `{year}.acl-long` volume, long papers; exact ACL aliases | Does not enumerate all Anthology venues, workshops, Findings or short papers. Verify requested volume, count, pagination and missing abstracts in the run. |
| [IJCAI proceedings](https://ijcai.org/proceedings/) | Official yearly index and main-track details; exact IJCAI aliases | Other tracks are not implied. Check track, year and all listed detail pages. IJCAI moved to `ijcai.org` and redesigned its pages in 2026; `www.ijcai.org` links redirect there and both layouts are read. |
| [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | Deposited venue/year metadata; first ISSN, collection DOI via `alternative-id`, otherwise container title | Conference enumeration requires collection DOI or ISSN. All collections must finish pagination. Exact identifiers improve scope but do not prove every paper was deposited. |
| [AAAI OJS](https://ojs.aaai.org/) | Official PDF and OJS BibTeX export for AAAI conference, symposium, and journal articles; AAAI DOIs resolve here | No archive index: Crossref enumerates AAAI with `issn: [2374-3468]`, and its records carry abstracts and the OJS landing URL. Crossref types them `journal-article`, so a `publication_types` filter must include that type. Live: AAAI-24 enumerated 2,867 records, all with abstracts; sample papers delivered. Since early November 2026 the OJS citation export answers HTTP 520 for every client, so AAAI fetches end `network_transient`: retry later and never substitute another citation format. |
| [NeurIPS proceedings](https://proceedings.neurips.cc/) | Official index `neurips-proceedings`: the yearly listing, main track and (from 2022) Datasets and Benchmarks; one paper page is read per paper for abstract and DOI. Official PDF and per-paper BibTeX file; legacy `papers.nips.cc` and `/paper/<year>/` links are accepted | The 2021 Datasets and Benchmarks site is separate and not listed. A DOI alone cannot be fetched (DOIs resolve to Curran Associates); discovery supplies the abstract URL. Live: 2019 listed 1,428 papers, all with abstracts; delivery verified. |
| [PMLR](https://proceedings.mlr.press/) | Official index `pmlr`: main-conference volumes of ICML, AISTATS, COLT, UAI, CoRL, ALT, ACML, L4DC, and CLeaR, read from each volume's official BibTeX file (one request per volume, abstracts included). Official PDF; BibTeX printed on the paper page | Workshop volumes are never matched. No DOIs; discovery supplies the paper URL. Live: ICML 2023 (v202) listed 1,828 papers, all with abstracts; delivery verified. |
| [CVF Open Access](https://openaccess.thecvf.com/) | Official index `cvf-open-access`: CVPR, ICCV, and WACV main-conference listings, including pre-2021 per-day pages; one paper page is read per paper for the abstract. CVF open-access PDF (accepted version plus watermark); BibTeX printed on the paper page | Not the final IEEE Xplore version; declare `publisher: IEEE` on the venue to keep the Crossref/IEEE route. Workshops are not listed. Live: WACV 2024 listed 846 papers, all with abstracts; delivery verified. |
| [Springer Link](https://link.springer.com/) | Journal articles (`/article/`) and book chapters such as LNCS (`/chapter/`); `10.1007` DOIs resolve here. Official PDF and the BibTeX file from Springer's citation export service (`citation-needed.springer.com`) linked on the page | Delivers when the page states that this network has access: open-access papers everywhere, subscription papers only on an entitled (for example campus) network; otherwise `access_required`. No login is attempted. Book, reference-work, and protocol pages are `unsupported_adapter`. Chapter exports carry the DOI only as the entry key. No venue enumerator; discovery uses Crossref. Live: two journal articles (one open access, one subscription on a campus network) and one LNCS chapter delivered. |
| [IEEE Xplore](https://ieeexplore.ieee.org/) | Official PDF/raw BibTeX with institution access | No official venue enumerator. Discovery uses metadata services. One CARSI institution has historical live validation; each additional profile requires its own smoke test. |
| [ACM Digital Library](https://dl.acm.org/) | Conditional official HTTP PDF/raw BibTeX acquisition | No official venue enumerator or production browser adapter. In November 2026 every non-browser request and an automated Chrome received a Cloudflare challenge (HTTP 403, `cf-mitigated: challenge`), so ACM papers are manual items whose message names the bot check. |
| [ScienceDirect](https://www.sciencedirect.com/) / [Elsevier APIs](https://dev.elsevier.com/) | Manual official file acquisition; API may resolve expected identity | No automated article-page or organization-login flow. API configuration and subscription entitlement are separate. |
| [OpenAlex sources](https://docs.openalex.org/api-entities/sources) (`openalex-venue`) | Venue/year enumeration for venues that declare exact `openalex_source` IDs, notably IEEE conference series that Crossref cannot enumerate; DOIs and abstracts included. Find IDs with `arp sources --find-openalex`, or name a built-in venue preset (INFOCOM, ICC, GLOBECOM, WCNC, VTC, ICDCS, ICNP, IWQoS, SECON, SIGCOMM) | Needs an OpenAlex API key. Metadata only; acquisition still goes to the publisher (IEEE Xplore for `10.1109`). OpenAlex may lag a recent edition; a finished slice with under half the previous year's works gets a `possible_upstream_lag` warning. Live: INFOCOM 2024 listed 262 and ICC 2024 940 papers; 1,191 of 1,202 had abstracts and all had DOIs. Publication years matched the edition for INFOCOM, ICC, GLOBECOM, WCNC, and VTC 2023–2025, but INFOCOM 2025 had only 25 works. |
| [OpenAlex API](https://docs.openalex.org/) / [Semantic Scholar API](https://www.semanticscholar.org/product/api) | Optional candidate search, enrichment and bounded citation graph | Configure the needed API independently. Search/ranking/neighbor limits and missing upstream records constrain recall. Never use metadata exports as final publisher BibTeX. |
| [ORCID public API](https://info.orcid.org/documentation/api-tutorials/api-tutorial-read-data-on-a-record/) / [DBLP](https://dblp.org/faq/How+to+use+the+dblp+search+API.html) | Public author works; supplied homepage DOI links and bounded Crossref author search supplement them | Identity ambiguity, truncation and errors remain explicit. No complete-bibliography claim. |

MinerU parses acquired PDFs; it is not a paper discovery source. The internal generic publisher adapter is not a public default adapter.

The priority venue list has not been selected. The table records existing capabilities, not certification of all meetings or journals. For each later priority venue, record its canonical name/aliases, years, tracks/types, official index URL, exact identifiers, expected counts, observed provider completion, sample identity verification and any missing coverage. Declare support only for the tested scope. An unsupported publisher remains `unknown` until its access and artifact contract is validated.

“Complete” in a provider ledger means that source's bounded enumeration finished. It never establishes that every real publication exists upstream. A topic result set, author bibliography, publisher artifact adapter and official venue index answer different questions.
