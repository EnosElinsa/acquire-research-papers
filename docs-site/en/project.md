# Development and citation

## Development

See [CONTRIBUTING.md](https://github.com/EnosElinsa/acquire-research-papers/blob/main/CONTRIBUTING.md) for development setup, Python/Node/PowerShell checks, wheel/skill builds, isolated installation, release validation, and building this documentation site. Participation is governed by the [Code of Conduct](https://github.com/EnosElinsa/acquire-research-papers/blob/main/CODE_OF_CONDUCT.md); questions and bug reports go through [SUPPORT.md](https://github.com/EnosElinsa/acquire-research-papers/blob/main/SUPPORT.md), and vulnerabilities through [SECURITY.md](https://github.com/EnosElinsa/acquire-research-papers/blob/main/SECURITY.md).

Every release is listed in the [changelog](https://github.com/EnosElinsa/acquire-research-papers/blob/main/CHANGELOG.md).

## Citation

If this tool supports published research, cite the release you used. [CITATION.cff](https://github.com/EnosElinsa/acquire-research-papers/blob/main/CITATION.cff) holds the citation metadata; GitHub shows it as "Cite this repository" on the repository page.
